# VK Online Tracker

Бот ВКонтакте, который следит за статусом «онлайн» другой твоей страницы и пишет:
когда зашла, когда вышла и сколько пробыла в сети. Нужен, чтобы проверять, не слишком ли часто
заходит в сеть скрипт на втором аккаунте.

**Вся настройка делается внутри бота, кнопками.** Из файлов нужен только ключ сообщества.
Входить в аккаунт не нужно: бот сам спрашивает ВК о статусе страницы.

```
🟢 В сети с 14:03:22 (с телефона)
до этого не был в сети: 3м 20с

🔴 Вышел из сети в 14:11:07
⏱ в сети: 7м 45с (с 14:03:22, с телефона)

⚡ Короткий заход: была активность в 14:07:41
⚠️ Частые заходы: 6 за последний час
🚫 Страница недоступна: заблокирована или заморожена
```

Если страница заходит через приложение (например, твой скрипт), в уведомлении будет
«приложение 1234567»: так видно, какое именно приложение даёт онлайн.

## Один раз в ВК: создать бота-сообщество

1. Создай сообщество (любое, можно закрытое).
2. **Управление → Сообщения:** включи сообщения сообщества. В «Настройках для бота» включи
   «Возможности ботов» (без этого не будет кнопок).
3. **Управление → Работа с API → Ключи доступа → Создать ключ.** Разреши «Управление сообществом»
   и «Сообщения сообщества». Скопируй ключ.
4. Там же, **Long Poll API → Включён**, версия API 5.199 или новее, тип события «Входящее сообщение».
   (Бот пробует включить это сам; если не вышло, он напишет об этом в консоль.)

## Быстрый старт

1. `cp .env.example .env` и вставь ключ в `VK_TOKEN`. Больше в файлах ничего править не нужно.
2. Запусти:
   - **Docker:** `docker compose up -d`
   - **Без Docker** (Python 3.10+):
     ```bash
     python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
     pip install -r requirements.txt
     python online_tracker.py      # то же самое, что python -m tracker
     ```
3. В консоли (в Docker: `docker compose logs`) появится **код привязки**. Открой страницу сообщества,
   нажми «Написать сообщение» и отправь этот код. Ты станешь владельцем, остальным бот отвечать
   не будет. (Либо впиши свой id в `OWNER_ID`, тогда код не нужен.)
4. В боте нажми **«👤 Выбрать страницу»** и пришли ссылку (`vk.com/durov`), короткое имя или id.

Всё. С этого момента уведомления приходят сами.

## Приватность отслеживаемой страницы

Бот смотрит на страницу как посторонний, поэтому на ней должно стоять:
**Настройки → Приватность → «Кто видит меня в сети» → «Все пользователи».**
Если там «Только я» или «Друзья», ВК не отдаёт статус, и бот напишет «Точный статус скрыт».

Если приватность верная, а бот всё равно пишет «скрыт», возможно, ключ сообщества не видит поля статуса.
Тогда задай `VK_STATUS_TOKEN`: сервисный ключ приложения (создай приложение на vk.com/apps?act=manage,
ключ в его настройках) или ключ пользователя. Статус будет читаться им, а бот останется на ключе сообщества.

## Что настраивается в боте

| Где | Что |
|---|---|
| **Главное меню** | статус сейчас, ⏸ пауза / ▶️ продолжить, 📊 статистика |
| **📊 Статистика** | заходы и время в сети за сегодня, 7 дней и всё время; 📜 история |
| **⚙️ Настройки → Страница** | за кем следим |
| **⚙️ Настройки → Опрос** | как часто спрашивать ВК: 5 / 15 / 30 / 60 / 120 с |
| **⚙️ Настройки → Порог** | сколько заходов за час считать «частыми» (3 / 6 / 10 / 20 или выкл) |
| **⚙️ Настройки → Уведомления** | отдельно: заход, выход со временем, предупреждения |
| **⚙️ Настройки → Часовой пояс** | список или свой: `Europe/Warsaw`, `+3` |
| **⚙️ Настройки → Помощь** | памятка по приватности |

Команды текстом: `меню`, `статус`, `статистика`, `настройки`.

## Чем отличается от Telegram-версии

- У ВК нет мгновенных уведомлений об онлайне, поэтому бот опрашивает `users.get` раз в N секунд
  (по умолчанию 15). Время захода и выхода точно до интервала опроса.
- Заход короче интервала опроса бот не успевает поймать «в сети», но видит по сдвигу «был в сети» и пишет
  ⚡ «Короткий заход». Такие заходы идут и в статистику (отдельно: «коротких»), и в предупреждение
  о частых заходах.
- ВК может гасить «онлайн» не сразу после ухода. Длительность считается по статусу, который отдаёт ВК
  (его видят и другие), а не по логу подключений самого скрипта.
- Если ВК блокирует, замораживает или удаляет страницу, бот пришлёт 🚫 сразу (это отдельное
  уведомление, его нельзя выключить).

## Работа 24/7

**Docker:** `docker compose up -d` (база лежит в `./data`, перезапуск её не теряет).

**systemd** (без Docker), `/etc/systemd/system/vk-online-tracker.service`:

```ini
[Unit]
Description=VK online tracker
After=network-online.target

[Service]
WorkingDirectory=/opt/vk-online-tracker
ExecStart=/opt/vk-online-tracker/venv/bin/python -m tracker
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now vk-online-tracker
journalctl -u vk-online-tracker -f
```

## Безопасность

- Ключи (`VK_TOKEN`, `VK_STATUS_TOKEN`) лежат только в `.env`, они в `.gitignore`. Не публикуй их.
- Бот отвечает только владельцу. Остальным: «Это приватный бот».
- Время на сервере должно быть синхронизировано (NTP), иначе длительности «плавают».

## Если что-то не так

| Симптом | Что делать |
|---|---|
| Бот не отвечает | Проверь: Long Poll включён, событие «Входящее сообщение» отмечено, сообщения сообщества включены, ключ с правом на сообщения. Подробности в консоли |
| Нет кнопок | Включи «Возможности ботов» (Управление → Сообщения → Настройки для бота) |
| Не приходит код привязки | Он только в консоли при запуске. Отправь его одним сообщением в личку сообщества |
| Уведомления не приходят | Сначала сам напиши сообществу (ВК не даёт боту писать первым); не стоит ли ⏸ пауза |
| «Точный статус скрыт» | Приватность страницы (см. выше); если она верная, задай `VK_STATUS_TOKEN` |
| «Не нашёл такую страницу» | Нужна страница человека, не сообщество: ссылка, короткое имя или id |
| Пропускает короткие заходы | Уменьши интервал опроса (Настройки → Опрос) |
| Ошибка про ключ при старте | Нужен ключ СООБЩЕСТВА (Управление → Работа с API → Ключи доступа) |
